# Puntos de control

Partidas guardadas para probar cosas desde un momento dado. En el juego: ✒ Ajustes → 📌 Puntos de control → «Cargar desde un archivo» (descarga antes el .json de aquí), y después «Volver aquí». Cada uno trae el día y cómo está el mundo («Ver el mundo»).

También se hacen con `tools/mano.js` (`/punto?nombre=…`, `/volver?i=-1`, `/mundo`).
