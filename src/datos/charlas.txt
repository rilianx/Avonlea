# Las charlas: lo que se dicen dos (o tres) cuando se encuentran, o mientras hacen algo juntos. Son líneas escritas
# (sin IA); el juego las lee al empezar (src/js/19-dialogos-de-pares.js). Están aquí, y no en el código, para que se
# puedan cambiar, ampliar (a mano o con una IA) y revisar con las mismas reglas que las escenas (tools/grafo.js revisa
# las condiciones).
#
# Cada charla: «=== id ===», sus campos (uno por línea, «campo: valor»), «---» y una línea por intervención,
# «quien: texto» (como en src/datos/guion.txt). Lo que se cuenta de alguien, entre paréntesis al comienzo: «(se ríe bajito)».
# Campos:
#   quienes: quiénes hablan (las personas: ana, diana, marilla…; o papeles: a, b, otro, que el código llena)
#   si: condiciones (las del guion: «ana_en_tv=se_queda», «ana_en_tv<decidida», «estacion:verano», «afecto:matthew:ana>=5»…)
#   donde: dónde tiene sentido («casa»: la cocina o el patio de Tejas Verdes; «gg»: la cocina; «dentro», «arroyo»…)
#
# Las clases de charla, por cómo empieza su id:
#   par:<quienes>:<n>   cuando esos dos o tres se encuentran (n: su número, desde 0; van en este orden). La primera que
#                       no se haya dicho y cuyas condiciones se cumplan; cuando se dijeron todas, saludos y chismes.
#                       Ana y Diana, además, solo cuando ya se conocen y no las tienen separadas.
#   pares:<clase>:<n>   dos vecinos que se cruzan, una línea cada uno (a y b): mixta (un niño, que habla primero, y un
#                       grande), kids (dos niños), big (dos grandes). Una al azar, de las que se cumplen.
#   ana_diana:<n>       Ana y Diana al cruzarse en el camino, una línea cada una.
#   suena:<n>           Ana sueña en voz alta con quien se cruza (otro le contesta; a un niño, el código lo tutea).
#   te, paseo           mientras toman el té (a: la que invita, b: la invitada) o pasean (a: la que invita, b: la otra).
#
